OIM 3600 — Course Setup

Computational Thinking with AI and Python · Spring 2027 · Babson College

1
Create your class GitHub account
  1. Go to github.com/signup.
  2. Email: your Babson email. If it is already used by another GitHub account, use a different email.
  3. Username: your first name, all lowercase, then -spring2027. Example: alex-spring2027.
  4. Finish the puzzle and enter the code GitHub emails you.
The username must match exactly: lowercase letters, one hyphen, -spring2027. No last name, numbers or dots. If two students share a first name, your instructor will tell you to add your last initial (julioa-spring2027).
2
Wait for the GitHub invitation

Your instructor adds you to the class. You will get an email from GitHub inviting you to Babson-CTAP. You do not need to click anything in it — setup accepts it for you. The invitation expires after 7 days, so run Step 3 soon after it arrives.

3
Run the setup command
  1. Make sure you are signed in to your class GitHub account in your web browser.
  2. Press the Windows key and type Windows PowerShell. Choose the one under Best match (not "x86" or "ISE") and click Open. Do not choose Run as administrator.
  3. Click Copy below, then right-click inside the PowerShell window to paste, and press Enter.
irm https://babson-ctap.github.io/install.ps1 | iex

During setup you will be asked two things:

  • "Do you want to allow this app to make changes?" — click Yes.
  • A GitHub code — write down the 8-character code, press Enter, type the code in the browser, and click Authorize. If asked anything else, press Enter.
Setup takes 20–30 minutes. Keep the laptop plugged in and awake, and do not close the windows. Do not press Ctrl+C — it cancels setup.
4
Open the course in VS Code

When you see SETUP COMPLETE, double-click the OIM3600 shortcut on your Desktop. Your course files are in student_repo. Work only there.

At the start of every class: open the OIM3600 shortcut, open the terminal (View → Terminal) and run ..\update50.ps1. It saves your work and downloads the latest course files.

If something goes wrong

Setup stopped with a red [FAIL] message
Read the message, fix what it says, and run the Step 3 command again. Running it again is always safe — it skips what is already done. If you are stuck, email your instructor the log file it names (in C:\ctap\logs).
"Your instructor has not added you to the class yet"
Email your instructor your GitHub username. Run Step 3 again after you receive the GitHub invitation email.
"You logged in as … Use your class account"
You authorized a different GitHub account. Sign out of GitHub in your browser, sign in to your class account, and run Step 3 again.
I clicked No on the Windows prompt
Run Step 3 again and click Yes.
